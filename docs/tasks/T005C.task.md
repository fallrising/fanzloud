# Outcome

Expose authenticated, bounded, version-1 replay-then-live WebSocket frames over the accepted T005A
subscription contract without mutating session/provider state.

# Inputs

ADR-0004, SPEC-T005C, accepted T005A subscription semantics, and accepted T005B authentication.

# Deliverables

- Exact WebSocket subscribe/frame/error schema
- Race-free replay/snapshot/live handoff
- Handshake deadline, cursor/gap checks, subscriber caps, lag cleanup, and disconnect independence

# Non-scope

Session ordering authority, mutating commands, polling, crash-durable replay, diff/prompt/code
frames, generic event protocols, or browser UI.

# Invariants

Stream connection, failure, lag, and disconnect never cancel or otherwise mutate a turn.

# Dependency Evidence

T005B must be Accepted before this task becomes Ready.

# Decomposition

T005A owns event ordering/retention/fanout. T005C owns only authenticated WebSocket transport.

# Machine Acceptance

Contract/property/integration tests cover replay order, no-gap handoff, reconnect deduplication,
future/gap cursor errors, invalid frames, auth/Origin, subscriber lag, disconnect cleanup,
redaction, and chunk/frame boundary behavior.

# Required Documentation Updates

Update SPEC-T005C, this task, traceability, HANDOFF, and `ACCEPT-T005C`.

# Risks and Gaps

Replay/live races and slow-consumer cleanup require repeated concurrency tests.
